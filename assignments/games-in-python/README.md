
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build the classic word-guessing Hangman game using Python strings, loops, and user input. This exercise helps reinforce string manipulation, control flow, and random selection.

## 📝 Tasks

### 🛠️ Build the Hangman Game

#### Description
Create a Python program that lets a player guess letters in a hidden word. The program should reveal correct guesses, count incorrect attempts, and end when the word is guessed or the player runs out of tries.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list
- Accept and validate letter guesses from the user
- Display the current progress of the word (_ _ _ format) after each guess
- Track and display the number of incorrect guesses remaining
- End the game with appropriate win or lose messages
- (Optional) Prevent repeated guesses from counting against attempts
